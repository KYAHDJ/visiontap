# VisionTap Android

The app opens the Oracle dashboard, keeps a foreground status monitor active, sends event-based Android notifications, and provides a resizable five-account home-screen widget.

The monitor checks every 30 seconds. The first successful response becomes the baseline and does not produce old-event notifications. Later verification, recovery, worker, scanner, loop, error, network, and withdrawal changes produce alerts.

After installing the APK:

1. Open VisionTap once and allow notifications.
2. Leave the low-priority “VisionTap monitoring” notification enabled for reliable background checks.
3. Long-press the Android home screen, choose **Widgets**, select **VisionTap**, and place the account bar.
4. Exempt VisionTap from aggressive battery optimization if the phone manufacturer stops background services.
