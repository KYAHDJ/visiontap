VisionTap ECNL Chrome Extension

INSTALL
1. Extract VisionTap-ECNL-Extension.zip.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the extracted folder containing manifest.json.

USE
1. Keep the VisionTap color scanner running at http://127.0.0.1:5566.
2. Open https://ecnlmediamarket.com/login and sign in manually.
3. Complete any security verification yourself.
4. Open https://ecnlmediamarket.com/solving-colors.
5. Use the extension popup to Start, Pause, or Reload.

This package contains ECNL color-task functionality only. It does not store login credentials.
